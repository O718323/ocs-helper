脚本在本地从源码构建后上传到仓库，由 GitHub Pages 以 main 分支根目录直接发布，脚本来源为 ocsjs/ocsjs（MIT 协议）。

安装脚本（v5.4.2）

点击后浏览器会交给脚本管理器处理安装。若没有任何反应，说明还没装管理器，请先完成下面第一步。

更新检测地址：ocs.meta.js

安装步骤

  1. 在 Chrome / Edge 安装脚本管理器：ScriptCat 或 Tampermonkey（篡改猴）。
  2. 回到本页，点上面的「安装脚本」，在管理器的安装确认页点「安装」。
  3. 打开网课平台（超星学习通、智慧树、职教云等）并登录，页面右下角会出现 OCS 悬浮窗。
  4. 进入视频或作业页面，脚本会自动开始运行；题库等配置在悬浮窗的教程与设置里。
